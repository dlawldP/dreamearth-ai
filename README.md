# DreamEarth AI

꿈속 자연환경을 지구과학 관점에서 분석하고, 실제 지구의 유사한 장소와 연결해 탐험하는 웹 앱입니다.

## 로컬 실행
```bash
npm install
npm run dev
```

## GitHub Pages 배포
GitHub 저장소의 **Settings → Pages → Build and deployment → Source**를 **GitHub Actions**로 설정하세요. 이후 `main` 브랜치에 push하면 자동 배포됩니다.

Gemini API 기능은 앱 안에서 사용자가 직접 API 키를 입력할 때만 사용할 수 있습니다. 키 없이도 내장 분석 및 탐험 기능을 체험할 수 있습니다.
